# Practical 1.7 — Factorial Calculation with Recursion

### Objective

To calculate the factorial of a number using a **recursive function**.

The factorial is calculated as:

```text
n! = n × (n-1) × (n-2) × ... × 1
```

For example:

```text
5! = 5 × 4 × 3 × 2 × 1
   = 120
```
